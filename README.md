## 📖 Overview

This repository contains open ended laboratory exercises and projects focused on **Database Systems**, with a particular emphasis on **Vector Databases** 🧠. These labs are designed to provide hands on experience with modern database technologies and practical implementations.

## 🚀 Getting Started

### 🔧 Prerequisites

<p>
<img src="https://img.shields.io/badge/Python-3.7+-3776AB?style=flat-square&logo=python&logoColor=white">
<img src="https://img.shields.io/badge/Jupyter-Notebook-F37626?style=flat-square&logo=jupyter&logoColor=white">
</p>

- Python 3.7 or higher
- Jupyter Notebook or JupyterLab
- Required Python packages, as specified in individual notebooks

### ▶️ Running the Labs

**Step 1 : Clone this repository**

```bash
git clone https://github.com/AbdulAzeemHashmi/Database-Systems-Open-Ended-Lab.git
cd Database-Systems-Open-Ended-Lab
```

**Step 2 : Extract the dataset, if needed**

```bash
unzip animal_dataset.zip
```

**Step 3 : Install required dependencies**

```bash
pip install -r requirements.txt   # if available
# or install packages as needed
```

**Step 4 : Open the notebook in Jupyter**

```bash
jupyter notebook Lab_14_Vector_Database.ipynb
```

**Step 5 : Follow the exercises and instructions within the notebook** 🎉
